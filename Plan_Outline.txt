DI CONTAINER FRAMEWORK — IMPLEMENTATION PLAN OUTLINE
Target: .NET 8.0 | No third-party libraries
================================================================================

CONFIRMED DESIGN DECISIONS
---------------------------
- Lifetimes:          Singleton, Transient, Scoped
- API style:          Inspired by MS DI, but our own naming and structure
- Injection:          Constructor injection + Property injection via [Inject] attribute
                      + Factory delegate registration
- Advanced features:  Circular dependency detection
                      IEnumerable<T> multi-registration resolution
                      IDisposable instance tracking and cleanup
                      Captive dependency guard (Scoped from root throws)
- Constructor pick:   Greedy — constructor with the most parameters wins
- Thread safety:      None — single-threaded use only

IMPLEMENTATION NOTES (deviations from original plan)
-----------------------------------------------------
- Injector.cs added (not in original plan): shared static helper containing
  ConstructorInject and PropertyInject logic. Both Container and ScopedContainer
  delegate to it via a resolver Func<Type, HashSet<Type>, object?> to avoid
  code duplication while keeping each class's own resolution context.
- ScopedContainer and ContainerScope are internal sealed (plan did not specify
  visibility). Users interact with them only through IContainer and IContainerScope.
- PropertyInject is always called after construction regardless of whether the
  instance came from a factory or reflection (plan implied factory-only; bug
  caught and fixed during implementation).
- Section 3 (Attributes) and Section 5 (Resolution Engine) were built together
  in one session since [Inject] is only meaningful in the context of the engine.
- IContainer extended with IDisposable (not in original plan): needed so callers
  can dispose the container through the interface without casting to a concrete type.

SECTION 1 — CORE VALUE TYPES                                           [DONE]
================================================================================

ServiceLifetime  (enum)
  Singleton  — one instance shared for the lifetime of the container
  Transient  — new instance on every resolution call
  Scoped     — one instance per explicit scope

ServiceDescriptor  (class, immutable after construction)
  Purpose: a single record describing how to build one service.

  Properties:
    Type            ServiceType              — the abstraction (e.g. IFoo)
    Type?           ImplementationType       — concrete class, instantiated via reflection
    ServiceLifetime Lifetime
    Func<IContainer, object>? Factory       — delegate-based creation (our name: IContainer)
    object?         Instance                — pre-built singleton; implies Singleton lifetime

  Invariants to enforce in the constructor:
    - Exactly one of ImplementationType, Factory, or Instance must be non-null.
    - If Instance is provided, Lifetime must be Singleton.

  Static factory helpers (for readable call sites):
    ServiceDescriptor.Singleton<TService, TImpl>()
    ServiceDescriptor.Singleton<TService>(TService instance)
    ServiceDescriptor.Singleton<TService>(Func<IContainer, TService> factory)
    ServiceDescriptor.Transient<TService, TImpl>()
    ServiceDescriptor.Transient<TService>(Func<IContainer, TService> factory)
    ServiceDescriptor.Scoped<TService, TImpl>()
    ServiceDescriptor.Scoped<TService>(Func<IContainer, TService> factory)

SECTION 2 — ABSTRACTIONS (Interfaces)                                  [DONE]
================================================================================

IServiceRegistry  (extends IList<ServiceDescriptor>)
  No extra members. Exists to give extension methods a stable target type.
  BuildContainer() is an extension method that returns an IContainer.

IContainer  (our equivalent of IServiceProvider — do NOT reuse System.IServiceProvider)
  object? Resolve(Type serviceType)
  Note: also expose typed extension methods via ContainerExtensions (Section 6).

IContainerScope  (our equivalent of IServiceScope)
  IContainer Container { get; }
  Implements IDisposable

IScopeFactory  (our equivalent of IServiceScopeFactory)
  IContainerScope CreateScope()

================================================================================

  Targets: Property
  Used to mark public properties for injection after construction.
  A property marked [Inject] must have a public setter.

SECTION 4 — REGISTRATION                                                [DONE]
================================================================================

ServiceRegistry  (implements IServiceRegistry, extends List<ServiceDescriptor>)
  No logic beyond List<ServiceDescriptor>.
  The BuildContainer() extension method (see below) lives outside this class.

ServiceRegistryExtensions  (static class)
  All methods return IServiceRegistry for fluent chaining.

  Singleton overloads:
    AddSingleton<TService, TImpl>()
    AddSingleton<TService>()                            — self-registration
    AddSingleton<TService>(TService instance)           — pre-built instance
    AddSingleton<TService>(Func<IContainer,TService>)   — factory delegate

  Transient overloads:
    AddTransient<TService, TImpl>()
    AddTransient<TService>()
    AddTransient<TService>(Func<IContainer,TService>)

  Scoped overloads:
    AddScoped<TService, TImpl>()
    AddScoped<TService>()
    AddScoped<TService>(Func<IContainer,TService>)

  Builder:
    BuildContainer(this IServiceRegistry) → IContainer
      Constructs and returns a new Container(registry).

  All overloads build a ServiceDescriptor and call registry.Add().

SECTION 5 — RESOLUTION ENGINE                                           [DONE]
================================================================================

--- 5a. Container (root, implements IContainer, IScopeFactory, IDisposable) ---

  Constructor:
    Accepts IEnumerable<ServiceDescriptor>.
    Builds internal map: Dictionary<Type, List<ServiceDescriptor>>
      (List because the same ServiceType can be registered more than once.)
    Initializes singleton cache:   Dictionary<Type, object>
    Initializes disposables list:  List<IDisposable>
    Self-registers: adds itself under both IContainer and IScopeFactory.

  Resolve(Type serviceType) — primary resolution entry point:
    1. If serviceType == typeof(IContainer)    → return this
    2. If serviceType == typeof(IScopeFactory) → return this
    3. If serviceType is IEnumerable<T>        → resolve all descriptors for T,
                                                  return as T[]  (see 5c)
    4. Look up last registered descriptor for serviceType (last-wins).
    5. If no descriptor found → return null.
    6. Delegate to ResolveDescriptor(descriptor, resolutionStack: new HashSet<Type>)

  ResolveDescriptor(ServiceDescriptor desc, HashSet<Type> stack) → object:
    Singleton:
      Check singleton cache. If hit → return cached value.
      Otherwise → Instantiate(desc, stack), store in cache, return.
    Transient:
      Always → Instantiate(desc, stack). Do not cache.
    Scoped (when called on root Container):
      Throw InvalidOperationException:
        "Cannot resolve scoped service '{serviceType}' from the root container.
         Use CreateScope() to obtain a scoped container."

  Instantiate(ServiceDescriptor desc, HashSet<Type> stack) → object:
    Priority order:
      1. desc.Instance is set         → return it directly (no injection needed)
      2. desc.Factory is set          → invoke factory(this)
      3. desc.ImplementationType set  → ConstructorInject via Injector
    Always after 2 or 3: PropertyInject via Injector
    After creation, if object implements IDisposable → add to disposables list.

  CreateScope() → IContainerScope  (from IScopeFactory):
    Returns new ContainerScope(this).

  Dispose():
    Iterate disposables list in reverse order, call Dispose() on each.
    Clear singleton cache and disposables list.
    Set a disposed flag; throw ObjectDisposedException on subsequent Resolve calls.


--- 5b. Injector (internal static helper — not in original plan) ---

  ConstructorInject(Type implType, HashSet<Type> stack, Func<Type,HashSet<Type>,object?> resolve):
    a. Get all public constructors via Type.GetConstructors().
    b. If none → throw InvalidOperationException("No public constructor on {implType}.")
    c. Sort by parameter count descending; take the first (greedy).
    d. Circular dependency check:
         If implType is already in stack → throw InvalidOperationException
         Else → stack.Add(implType)
    e. For each constructor parameter:
         resolved = resolve(paramType, stack)
         If resolved is null → throw InvalidOperationException
    f. stack.Remove(implType)
    g. Return Activator.CreateInstance(implType, resolvedArgs[])

  PropertyInject(object instance, HashSet<Type> stack, Func<Type,HashSet<Type>,object?> resolve):
    a. Get all public properties where [Inject] attribute is present.
    b. For each: verify public setter exists or throw InvalidOperationException.
    c. resolved = resolve(property.PropertyType, stack)
       If resolved is null → throw InvalidOperationException
    d. property.SetValue(instance, resolved)


--- 5c. IEnumerable<T> resolution ---

  When Resolve receives a type of IEnumerable<T>:
    Look up all descriptors registered under T (not just the last one).
    For each descriptor, call ResolveDescriptor.
    Collect results and return as a T[].


--- 5d. ScopedContainer (internal, implements IContainer, IDisposable) ---

  Purpose: wraps the root Container; adds its own cache for Scoped instances.

  Constructor:
    Accepts root Container (internal reference, not exposed publicly).
    Initializes scoped cache:       Dictionary<Type, object>
    Initializes scoped disposables: List<IDisposable>

  Resolve(Type serviceType):
    1. IContainer    → return this
    2. IScopeFactory → return root (so CreateScope branches from root)
    3. IEnumerable<T> → resolve all via own resolver, routing by lifetime
    4. Look up last descriptor via root's internal descriptor map.
    5. If not found → return null.
    6. Singleton  → delegate to root.ResolveCore (root owns the singleton cache)
    7. Transient  → own Instantiate; track IDisposable in own disposables
    8. Scoped     → check scoped cache; own Instantiate if miss, cache result

  Dispose():
    Dispose all scoped disposables in reverse order.
    Clear scoped cache. Set disposed flag.


--- 5e. ContainerScope (internal, implements IContainerScope, IDisposable) ---

  Properties:
    IContainer Container  →  the ScopedContainer for this scope

  Constructor:
    Creates new ScopedContainer(rootContainer) and assigns to Container.

  Dispose():
    Calls Dispose() on the ScopedContainer.

SECTION 6 — RESOLUTION HELPERS                                         [ TODO ]
================================================================================

ContainerExtensions  (static class, extension methods on IContainer)

  T? Resolve<T>()
    → (T?) container.Resolve(typeof(T))

  object ResolveRequired(Type serviceType)
    → result = Resolve(serviceType)
       if null → throw InvalidOperationException(
                   "No registration found for '{serviceType}'.")
       return result

  T ResolveRequired<T>()
    → (T) ResolveRequired(typeof(T))

  IEnumerable<T> ResolveAll<T>()
    → (IEnumerable<T>?) Resolve(typeof(IEnumerable<T>)) ?? Enumerable.Empty<T>()

  IContainerScope CreateScope(IContainer container)
    → ((IScopeFactory) container.ResolveRequired<IScopeFactory>()).CreateScope()

SECTION 8 — DEMO IN Program.cs                                         [ TODO ]
================================================================================

Define demo services:

  interface ILogger
  class ConsoleLogger : ILogger
    - Constructor: ()
    - Logs to Console with a unique instance ID (Guid) so we can tell instances apart

  interface IMessageService
  class EmailMessageService : IMessageService
    - Constructor: (ILogger logger)
    - Has one [Inject] property: public ILogger SecondaryLogger { get; set; }

  interface IRequestHandler
  class RequestHandler : IRequestHandler
    - Constructor: (IMessageService messages, ILogger logger)

Registration:
  var registry = new ServiceRegistry();
  registry.AddSingleton<ILogger, ConsoleLogger>();
  registry.AddTransient<IMessageService, EmailMessageService>();
  registry.AddScoped<IRequestHandler, RequestHandler>();
  var container = registry.BuildContainer();

Demonstrate Singleton (same instance, same ID):
  var log1 = container.ResolveRequired<ILogger>();
  var log2 = container.ResolveRequired<ILogger>();
  Assert ReferenceEquals(log1, log2) == true

Demonstrate Transient (different instances, different IDs):
  var msg1 = container.ResolveRequired<IMessageService>();
  var msg2 = container.ResolveRequired<IMessageService>();
  Assert ReferenceEquals(msg1, msg2) == false

Demonstrate Property Injection:
  var msg = (EmailMessageService) container.ResolveRequired<IMessageService>();
  Assert msg.SecondaryLogger != null
  Assert ReferenceEquals(msg.SecondaryLogger, log1) == true  (singleton)

Demonstrate Scoped (same within scope, different across scopes):
  using var scope1 = container.CreateScope();
  using var scope2 = container.CreateScope();
  var h1a = scope1.Container.ResolveRequired<IRequestHandler>();
  var h1b = scope1.Container.ResolveRequired<IRequestHandler>();
  var h2  = scope2.Container.ResolveRequired<IRequestHandler>();
  Assert ReferenceEquals(h1a, h1b) == true   (same scope, same instance)
  Assert ReferenceEquals(h1a, h2)  == false  (different scope)

Demonstrate Captive Dependency Guard:
  Try: container.ResolveRequired<IRequestHandler>()  — must throw

Demonstrate Circular Dependency Detection:
  Register a class Circular whose constructor takes Circular.
  Try: container.ResolveRequired<Circular>()  — must throw with clear message

Demonstrate IEnumerable<T> resolution:
  Register two ILogger implementations.
  var loggers = container.ResolveAll<ILogger>();
  Assert loggers.Count() == 2

Demonstrate IDisposable cleanup:
  Have ConsoleLogger implement IDisposable and print "Disposed" in Dispose().
  Wrap a scope in using; verify Dispose is called when scope ends.
  Dispose the root container; verify singleton disposables are cleaned up.

SECTION 9 — ERROR HANDLING CONTRACT                                    [N/A]
================================================================================

Implemented inline during Sections 4–5. Reproduced here for reference.

ArgumentNullException:
  - Null ServiceDescriptor passed to registry
  - Null type or instance passed to extension methods

InvalidOperationException:
  - Circular dependency detected (include type name in message)
  - ResolveRequired cannot find a registration
  - Scoped service resolved from root container (captive dependency guard)
  - No public constructor on implementation type
  - Constructor or [Inject] property parameter cannot be resolved
  - [Inject] applied to a property without a public setter

ObjectDisposedException:
  - Resolve called on a disposed Container or ScopedContainer
